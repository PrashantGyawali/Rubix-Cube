# Rubix-Cube

[View Live Demo](https://prashantgyawali.github.io/Rubix-Cube/)

A 3D interactive Rubik's Cube simulator built using JavaScript and Three.js. This project provides a smooth 3D experience with responsive controls.

## Features

* 3D visualization rendered with Three.js.
* Interactive cube rotation and manipulation.
* Responsive design for desktop and mobile devices.

## How to Run

1. Clone this repository:
```bash
git clone https://github.com/PrashantGyawali/Rubix-Cube.git
```

2. Open `index.html` in any modern web browser.
